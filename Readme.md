# ⚡️ jsonToApi

**Generate mock APIs in 5 seconds.  
No login. No setup. Just paste JSON.**

---

## ✨ Features

- Paste JSON → instant REST API
- Auto-generated CRUD routes
- Shareable public endpoint
- No auth / no config
- Works straight from browser
- Lightweight and fast
- Built for frontend devs, not backend simulation

---

### 🚀 How it works

1. Open the website  
2. Paste your JSON  
3. Click **Generate**  
4. Get a live API link instantly  

Done.
